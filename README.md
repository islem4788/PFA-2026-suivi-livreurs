# Intelligent Delivery Tracking System

## Overview
An embedded IoT system designed to detect aggressive driving behavior using sensor data and machine learning.

## Technologies
- STM32F429
- MPU6050
- ESP32
- Embedded C
- Python
- XGBoost
- HTML, CSS and JavaScript

## Key Features
- Sensor data acquisition using STM32F429 and MPU6050
- Wireless data transmission using ESP32
- Driving behavior detection using an XGBoost model
- Web dashboard with real-time alerts

## System Architecture
STM32F429 + MPU6050 → ESP32 → Backend → Machine Learning → Web Dashboard

## Project Structure
- `firmware/`: Embedded software
- `machine-learning/`: Model training and prediction
- `dashboard/`: Web interface

Designed and integrated the embedded sensing system, communication components, machine learning model and web dashboard.
